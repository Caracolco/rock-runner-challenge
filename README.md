# Rock Runner Challenge

Hasta 15 participantes por dinámica. La disponibilidad del registro se consulta en el juego. Los datos, el panel administrativo y el banco de respuestas se mantienen en el backend privado.

Política oficial: https://seguro.radioacktiva.com/privacidad.html

## Demo: La Ruta de los Tesoros Escondidos

Demo jugable en 3D (Mundo 1: Carnaval de Barranquilla) en [`ruta-tesoros/`](ruta-tesoros/index.html). Tres niveles (Encuentra el ritmo, Recupera los colores, Enciende la fiesta), mapa de Colombia con la ruta, espacios de marca genéricos ("TU MARCA") y final con comparsa. No guarda ni envía datos. Funciona como página estática: basta con abrir `ruta-tesoros/index.html` desde un servidor web (por ejemplo GitHub Pages).
